# 世界観資料(下書き)

企画書([game_design.md](game_design.md))は意図的に細部をぼかしている。ここでは
開発のために必要な「裏側の事実」を具体的に決める。プレイヤーに全部を見せるための
資料ではなく、矛盾なく伏線を張るための開発用の資料。

**(仮)** の付いている項目は特に変更・相談歓迎。

## 街: ヴェスペル(仮)

- 教会の「夕べの祈り」を意味する言葉が街の名の由来(仮)。信仰と密接な街であること
  を名前でも示す。
- 主要な地区:
  - **教会区**: 聖なる教会の本拠がある地区。街の中心に近い高台。
  - **商業区**: 昼の市場、まっとうな商店が並ぶ。
  - **裏路地**: 商業区の裏手。夜になると「夜市」が立つ。主人公の店もここにある。
  - **東門**: 街の東の出入り口。街道と、後述する「旧魂坑」への道につながる。
  - **西門**: 街の西の出入り口。特筆すべき設定は今のところなし(必要になったら足す)。

## 主人公の店: 三日月堂(仮)

- 裏路地の一角にある小さな店。主人公が始めたのか継いだのかは要相談
  (継いだ方が「なぜ自分がここにいるか」に理由ができて動かしやすいと思う)。
- 表向きは道具屋。裏で夜市の客を相手にしている。

## 「魂入れ」の歴史

- およそ**15年前**まで、魂を物に宿す技術は聖なる教会公認の研究として存在した
  (仮に「魂坑研究」と呼ぶ)。研究拠点は東門を出てしばらく行った先、現在は
  封鎖されている施設「**旧魂坑**」。
- 15年前、旧魂坑で大規模な実験事故が発生。多数の犠牲者を出した。事故後、
  技術は禁術に指定され、旧魂坑は封鎖。研究記録の大半は教会が回収・封印したとされる
  (実際に教会がどこまで握り潰したかは不明 — ここは物語で明かしていく部分)。
- **主人公は事故の生存者の一人**(当時は子供〜少年少女、年齢は要相談)。身体に
  「魂との共鳴」が残っているが、本人はその自覚がない。

## 現在、なぜ魂入り商品が増えているのか(裏の真相・仮)

- 旧魂坑には、事故後も研究資料や設備の残骸が残っていた。何者か(あるいは複数の
  勢力)が近年そこに出入りし、禁術を密かに再開・利用し始めている。
- この人物 **(仮称: 教授)** は、事故の研究に関わっていた生存者の一人。目的は
  まだ未確定(要相談。候補: 事故で失った誰かの魂を取り戻そうとしている/研究への
  執着が捨てきれない/教会や国への復讐、など)。
- 教授が直接夜市に顔を出すことはなく、墓荒らし窃盗団(資料パネルで既出の
  「形見を騙る窃盗団」)や、イレアの護符を買い取りに来た「フード姿の男」のような
  仲介者を通じて、魂入り品が少しずつ夜市に流れ込んでいる。
- **最近、東門の騎士が増えている**(ダロンの噂として実装済み)のは、教会か国、
  あるいはその両方が旧魂坑の異変に気づき、調査・警戒を強化し始めたため。
  これが物語中盤の緊張を作る軸になる。

## 夜市

- 表向きは存在しない非合法な市場。裏路地に、日が沈むとどこからともなく立つ。
- 「元締め」と呼ばれる管理者が全体を仕切り、店主から毎晩の上納金を徴収する。
  上納金は名目上「場所代・警備・情報網の維持費」(企画書14章の通り)。
- 元締めが上納金にうるさいのには裏の理由がある(仮): 彼は15年前の事故を知る
  数少ない生き証人で、「金の管理がずさんな店ほど、質の悪い(=危険な)商品を
  平気で扱うようになる」ことを身をもって知っている。上納金の取り立ては、彼なりの
  「夜市を暴走させない歯止め」でもある。単なる悪役にはしない。

## 聖なる教会

- 「魂は天へ還るべき」という教義。魂入り品の摘発・回収を推奨するが、実働部隊は
  多くない。
- 主人公の店には、教会の若い調査員が時々客のふりをして訪れる。**(仮称: シスター・
  マレン)**。教会の公式見解と個人の考えの間で揺れている人物にする(教会=悪、では
  なく、教会自身も一枚岩ではないことを彼女を通じて見せる)。
- 教会上層部が旧魂坑や事故についてどこまで知っているか・隠しているかは、物語終盤
  まで明かさない伏せ球にする。

## 用語整理

| 用語 | 説明 |
| --- | --- |
| 旧魂坑 | 15年前の事故現場。東門の外。現在は封鎖・立入禁止だが出入りする者がいる |
| 元締め | 夜市の管理者。上納金を徴収する |
| 教授(仮) | 現在の魂入り品流通の黒幕(仮)。姿を見せない |
| 共鳴 | 主人公が事故で得た、魂判別機なしで魂反応を感じ取れる体質 |
