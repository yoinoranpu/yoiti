# ChatGPTに完成イメージ図を描いてもらうための資料

## 使い方

1. https://yoinoranpu.github.io/yoiti/ を開く
2. 下記「スクリーンショットの撮り方」の通りに2枚撮る
3. ChatGPTに「ゲーム説明」を最初に貼る(1回だけでOK、以降の会話で覚えている)
4. スクリーンショットを1枚ずつ添付し、対応するプロンプトを貼って送る

---

## ゲーム説明(最初に貼る)

```
これから見せる画像は、開発中のインディーゲーム『夜市(よいち)』のUIスクリーン
ショットです。

ジャンル: ダークファンタジー・観察/会話/推理・商売シミュレーション
コンセプト: プレイヤーは、夜にだけ開かれる闇市場「夜市」で小さな店を営む商人。
盗品・魔術具・呪具・違法に魂を宿した商品を持った客が訪れる。客の見た目や発言、
商品の状態を観察し、聞いた情報を組み合わせて、買うか断るか通報するかを自分で
判断する。7日間生き延びることが目標。

絵柄: ドット絵(pixel art)。アンチエイリアスのない、はっきりしたピクセル単位の
輪郭。パレットは暗い紫紺(#0e0b12〜#1a1520)を基調に、ランタンの暖色の灯り
(#c9a24a)だけが強く光る、という明暗のコントラストが特徴。
参考にしている作品: Moonlighter(ドット絵の店番UI)、Stardew Valley(小さい
ドット絵でも表情が伝わるNPC)、Papers, Please(検査官視点の事務的な緊張感)。

今から見せるスクリーンショットは、レイアウトや仕組みは固まっているが、UIの
装飾(ボタンのアイコン化、枠の質感、灯りの演出など)がまだ作り込まれていない
「実装途中」の状態です。このあと、画面ごとに「完成した時のイメージ図」を
描いてほしいとお願いします。
```

---

## 画面1: メインの接客画面(最優先)

ゲームの9割を占める中心画面。ここが良くなれば全体の印象が大きく変わる。

### スクリーンショットの撮り方

1. サイトを開いて「店を開ける」を押す
2. 最初の客(ダロン)の画面で「商品を詳しく調べる」を押す
   (→ カウンターの上に商品アイコンが乗った状態になる)
3. この状態でスクリーンショット

### プロンプト

```
この画像は、ゲーム『夜市』の接客画面です。現状の構成:
- 奥に店内の背景(棚・ランタン)
- 客がカウンターの奥に立っている(下半身はカウンターに隠れている)
- カウンターの上に、調べた商品のアイコンが乗っている
- 画面右上に3つのアイコン(資料/まとめた情報/見た情報を開くボタン)
- 画面下に会話ログと、プレーンなテキストボタン(話す/調べる/判断する)
- 画面上部にプレーンなテキストの数値表示(所持金・上納金・在庫・日数)

このレイアウト・構図はそのまま維持した上で、「この画面が完成した時の
コンセプトイメージ」をドット絵で描いてください。具体的には:
- 下のテキストボタンを、アイコン+短いラベルの質感のあるボタンに
- 上部の数値表示に小さなアイコンを添える(所持金=金貨、上納金=金袋、
  在庫=行商袋、日数=月の満ち欠け、など)
- カウンターやパネルの枠に、使い込まれた木材・古びた金属・羊皮紙のような
  質感を足す(今はのっぺりしたUIボックスなので)
- ランタンの灯りがふわっと滲むような光の演出、埃や湯気などの微妙な空気感を足す
- 色調は今のスクリーンショット通り(暗い紫紺+琥珀色の灯り)を維持

日本語のテキストは正確に再現できなくて構いません(読めない飾り文字で十分)。
あくまで「UIの質感・雰囲気の完成イメージ」を見たいので、レイアウトを大きく
変えずにお願いします。
```

## 画面2: タイトル画面

第一印象を決める画面。背景はすでに雰囲気があるので、タイトルロゴや
ボタンの質感を中心に見たい。

### スクリーンショットの撮り方

1. サイトを開いて、最初の画面(何も押さない状態)でスクリーンショット

### プロンプト

```
この画像は、ゲーム『夜市』のタイトル画面です。現状の構成:
- 夜市の通りの背景(提灯が並ぶ、雰囲気のあるドット絵)
- 中央に「夜市」というプレーンな文字だけのタイトル
- サブタイトルのテキスト
- 「店を開ける」という、装飾のないシンプルな枠のボタン

この背景・構図はそのまま維持した上で、「この画面が完成した時のコンセプト
イメージ」をドット絵で描いてください。具体的には:
- 「夜市」のタイトル文字に、和風の提灯や墨文字のような質感・装飾を加える
- 「店を開ける」ボタンに、木製の看板や札のような質感を足す
- 手前に軽く人影や小道具のシルエットを足して奥行きを出してもよい
- 提灯の灯りがふわっと滲む・小さな灯りの粒子が舞うような演出

色調は今のスクリーンショット通り(暗い紫紺+琥珀色の提灯の灯り)を維持して
ください。日本語のテキストは正確に再現できなくて構いません。
```

## 補足

- 査定(売り)画面は接客画面とレイアウトが同じなので、別途描いてもらう必要は
  基本的にない。
- 出てきたイメージ図は、そのまま実装するわけではなく「方向性を確認するための
  ラフ」として使う想定。気に入った要素があれば、それをもとに
  [illustration_requests.md](illustration_requests.md) 形式で追加のドット絵
  プロンプトを作っていく。
