# ChatGPTへのスクショレビュー依頼文(買取鑑定画面)

買取鑑定画面(night screen、客との接客〜鑑定机)のスクリーンショットと
一緒に貼る説明文。「何を改善すべきか」を具体的に指摘してもらうための依頼。

```
『夜市(よいち)』というダークファンタジーの個人開発ゲームの、商品買取
(接客)画面のスクリーンショットです。前回レビューしてもらった内容を
反映して改修した後の最新状態です。

【ゲーム概要】
闇市場の露店の店主として、7日間を生き延びることを目指すシミュレーション
ゲームです。毎晩訪れる客と会話し、持ち込まれた商品を鑑定し、買い取るか
どうかを判断します。買い取った商品は翌日以降、別の買い手に売って利益を
出します。参考にしている作品は『Papers, Please』(資料と向き合う緊張感)、
『Moonlighter』(店番と商品管理の感覚)、『Strange Horticulture』(机の上で
対象を観察する感覚)です。見た目はダークな紫紺+琥珀色を基調にしたドット絵
で、この配色とドット絵のタッチ自体は変えられません。

【この画面の役割・操作の流れ】
1. 客が声をかけてくる(画面上部の吹き出しに客のセリフが出る)
2. 客(立ち絵)をクリックすると会話メニューが開き、話題を選んで情報を聞ける
3. 画面下半分が「鑑定机」になっていて、中央に置かれた商品(今回は片手剣)
   から線で伸びる鑑定札(刃/傷/重さ/匂い/材質/魔力/柄の刻印/状態、計6〜8個)
   を1つずつクリックして、隠された情報を確認する。未鑑定の札は「部位名+？」
   の薄い札、鑑定済みは内容が書き込まれた明るい紙の札になる
4. 「調べられる箇所」の数とは別に「残り」回数があり、虫眼鏡アイコンの
   列(ピップ)で残り回数が一目で分かる。使うたびに1つ暗くなる
5. 鑑定机の右側、石の台座に置かれた魂判別機を、ドラッグ(またはクリック)で
   商品にかざすと「魂が入っているかどうか」を調べられる
6. 得られた情報をもとに、画面中段のボタンで「言い値で買う/値切る/断る/
   通報する」のいずれかを選ぶ(鑑定机とは区切り線で分けている)
7. 右上のアイコンから「資料」「まとめた情報」「見た情報」のパネルを個別に
   開いて確認できる(常時表示ではない)

UIは角丸や1pxの細い枠、ぼかし影のような「いかにもWebアプリ」な表現を避け、
面取り(ベベル)と硬い影だけで立体感を出すドット絵調のスタイルに統一して
あります。鑑定机と魂判別機の背景は1枚のイラスト(木の机+羊皮紙の地図+
石の台座)です。

このスクリーンショットを見て、UI/UXとして改善したほうがいい点を具体的に
指摘してください。特に次の観点でお願いします。
- 情報の優先順位・視線の流れ(最初にどこを見ればいいか分かりやすいか)
- 余白・配置のバランス、窮屈に見える部分
- 色や文字の読みやすさ・コントラスト
- 「店主として調査している」没入感をもっと出せそうな余地
- 逆に、良く出来ている・変えない方がいい部分があればそれも教えてほしい
```
