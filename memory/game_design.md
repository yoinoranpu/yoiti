# 『夜市』企画書

> 元は2026-09-24にユーザーが持ち込んだ企画書。実装しながら決まったことは
> [decisions.md](decisions.md) に追記していく。ここ(このファイル)は
> 「変わらない世界観・コンセプトの原本」として基本触らない。

## 1. ゲーム概要

- ジャンル: ダークファンタジー・観察・会話・推理・商売シミュレーション
- コンセプト: 「客の話を聞き、商品を見て、自分で判断する。」
- プレイヤーは、夜にだけ開かれる闇市場「夜市」で小さな店を営む商人。
- 夜市には、普通の市場では売買できない商品(盗品、魔術具、呪われた道具、禁制品、
  違法に魂を宿した商品)を持った客が訪れる。
- 客から話を聞き、商品を調べ、得た情報をもとに取引を行う。
- **基本的に「正解」は存在しない。** 客を信用するか疑うか、危険な商品を買うか断るか、
  教会に情報を売るか夜市のルールを守るか。どの選択にも利益と不利益があり、
  プレイヤーの行動でその後の世界が変化する。

## 2. ゲームの基本構造

毎晩のループ:

```
客が来る → 客を見る → 商品を見る → 客と話す → 情報を組み合わせる
→ 取引するか判断する → 結果が発生する → その日の利益を得る → 上納金を納める
```

毎晩、夜市には一定額の上納金を納めなければならない。払えなければ店を維持できず
ゲームオーバー。「安全に商売する」か「危険を承知で高利益の商品を扱う」かを
常に判断させる。

## 3. 世界観 — 魂

- 魂は実在する。人間が死ぬと魂は肉体を離れ、本来は天へ還るとされる。
- 魔術によって魂を物に宿す技術が存在し、宿した物にはその魂の性質が反映される
  (強い戦士の魂を宿した剣は強い武器になる、等)。
- そのため魂を宿した商品には非常に高い価値がある。

## 4. 魂を物に入れる技術

- かつて正式な魔術技術として研究されていたが、過去に大規模な実験事故が発生し
  多くの犠牲者を出した。
- 事故後、魂を物に宿す技術とその商品の流通は法律で禁止され、現在は禁術。
- それでも「強い魂を宿した武器は強い」という事実は変わらないため、違法でも
  需要は存在する。技術自体も裏社会で密かに受け継がれている。

## 5. 聖なる教会

- 世界で広く信仰されている宗教組織。「魂は天へ還るべきもの」を教義とし、
  魂を物に宿す行為を禁忌として取り締まる。
- 魂入り商品を見つけたら教会への届け出が推奨されている。
- ただし教会がすべての真実を知っているわけではない
  (「魂は本当に天へ還るのか」「過去の魂研究について教会は何を知っているのか」など、
  プレイヤーには分からない部分が残る)。

## 6. 夜市

- 夜になると開かれる非合法な市場。国に認められた市場ではないが、普通の市場で
  扱えない商品を必要とする人間がいるため長く存続している。
- 暗黙のルール: 「夜市で得た情報を外に漏らさない」。客の素性を探ること自体は
  禁止されていないが、夜市の商売を壊す行動をすれば夜市から敵視される。

## 7. 主人公

- 夜市で小さな店を営む商人。過去の多くは不明。
- 過去に発生した大規模な魂研究事故の被害者の一人で、身体に通常の人間にはない
  「魂との共鳴」が残っている。**ただし主人公自身はその事実を知らない。**
- ゲーム開始時点ではプレイヤーにも詳しい説明はされない。

## 8. 魂判別機

- ゲーム開始時、主人公は夜市から「魂判別機」を借りている。
- 商品にかけると「魂反応: あり / なし」だけがわかる。誰の魂か、なぜ入っているか、
  どんな人物だったかはわからない → プレイヤーが客の話や商品の状態から推理する。

## 9. 魂判別機を失う(中盤の展開)

- ある日、上納金を払えなくなり、夜市の管理者が魂判別機を回収する。
- 翌日、商品を調べていると商品情報の紙に青白い文字で「魂反応: あり」と
  浮かび上がる → 判別機なしで魂を判別できるようになっている。
- これは過去の実験事故で主人公に残った「魂との共鳴」によるもの。
  **この事実はゲーム序盤では説明せず、物語を進める中で徐々に判明させる。**

## 10. 情報を得る方法(意図的に限定する)

- 「客を見る」: 服装・装備・紋章・傷・持ち物・態度など。
- 「商品を見る」: 状態・材質・傷・刻印・魔力・魂反応など。
- 「客と話す」: 入手経路・目的・人物関係・最近の出来事など。
- これ以外の万能な検索システムは存在しない(戸籍検索や全商品データベースなどは不可)。
  プレイヤー自身が見た情報と聞いた情報を組み合わせて判断する。

## 11. 会話システム

- 単なるストーリーイベントではなく重要なゲームシステム。
- 客の発言(例: 「最近、東門に騎士が増えている」)を覚えておき、後から来る別の客
  (例: 東門から来た客)への警戒に使える。
- 客の話がすべて正しいとは限らない(嘘・勘違い・噂・誇張もある)。
  「情報を集める」だけでなく「その情報を信用するか」もプレイヤーの判断。

## 12. 「正解」は存在しない

- ミスという概念を作らない。怪しい客を見逃しても単純な「失敗」ではなく、
  その後の展開(別の場所で事件を起こす/教会からの信用/夜市からの警戒など)に
  つながるだけ。「正しい選択肢を当てる」のではなく「自分ならどうするかを決める」
  ゲーム。

## 13. TRPG的なゲーム体験

- 「情報を集める → 判断する → 世界が反応する」の繰り返しが楽しさの core。
- 例: 指名手配犯の噂を聞く → 怪しい客が来る → 質問する → 嘘をつく →
  通報する → 実は本物だった → 「夜市に情報を流した人物がいる」と疑われる、等。
  プレイヤーの選択で以降の出来事が変わり続ける。

## 14. 上納金

- 毎晩、店の維持のために一定額の上納金が必要(店舗使用料・警備・情報網・
  商人の保護・夜市の維持費など)。払えなければ店を維持できない。
- 「安全な商売」か「危険だが高利益な商品」かの天秤が常に働く
  (普通の剣 < 魂入りの剣 < 大量の魂を使った禁制品、の順でハイリスク・ハイリターン)。

## 15. 世界の裏側

- 過去の魂研究、大規模な実験事故、犠牲者、技術の出自、教会が過去に何を
  知っていたか、夜市の成り立ち、主人公が事故の生存者である理由 — それぞれに
  背景があるが、ゲーム中で全部は説明しない。プレイヤーが必要とする情報だけ提示し、
  それ以外は断片的な記録・会話・商品・人物から想像させる。

## 16. ストーリーの基本構造

- 序盤: 「客が来る→商品を調べる→金を稼ぐ→上納金を払う」生活。
- 魂入り商品が少しずつ増えていく(単純な魂入り武器 → より危険な商品)。
- 「最近、魂入りの商品が妙に増えている」ことに気づき、過去の情報と照らし合わせると
  現在の夜市の魂商品と過去の大規模事故のつながりが見えてくる。主人公自身も
  事故と関係があることが明らかになる。真実を追うかどうかはプレイヤー次第。

## 17. ストーリーの重要な方針

- **「主人公が世界を救う物語」にはしない。** あくまで夜市の商人。
- 「今日の上納金をどうするか」「目の前の客を信用するか」「危険な商品を買うか」
  「教会に情報を渡すか」という小さな判断の積み重ねの結果として、世界の大きな
  出来事に巻き込まれていく構造にする。

## 18. 最終的なゲーム体験

- プレイスタイルは人によって変わる: 教会に協力する店主 / 夜市に忠実な店主 /
  危険な魂商品を扱う店主 / 客を助ける店主 / 金だけを追い求める店主 /
  過去の事故を調べ続ける店主、など。
- 目指すのは「間違いを見つけるゲーム」ではなく「限られた情報の中で、自分の判断に
  よって夜市を生きるゲーム」。
